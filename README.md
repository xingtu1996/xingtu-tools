## 🎯 这是什么

`xingtu-tools` 是行途开源矩阵的**工程脚本资产仓**。收录在真实项目维护中打磨的通用脚本——不绑定任何特定公司/业务，可直接复用。

## 📦 用法

```bash
# 查看脚本
ls scripts/

# 直接运行（多数脚本零依赖）
./scripts/network-diag.sh
```
