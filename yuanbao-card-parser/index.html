元宝卡片解析器

把微信元宝分享页源码或卡片文本解析为结构化数据，方便投喂 AI 或归档到素材库。

输入

如何获取 HTML 源码？
  1. 在微信内打开该分享链接（会显示完整对话内容）。
  2. 点击右上角「···」→ 选择「在浏览器打开」或用系统浏览器打开。
  3. 在浏览器页面空白处右键 → 「查看网页源代码」；或按 Ctrl+U / Cmd+Option+U。
  4. 全选并复制整个源码，粘贴到左侧输入框。
  5. 也可以直接在微信内长按页面 → 复制链接，然后用工作空间里的 Python 工具抓取：
    python tools/yuanbao-share-parser/yuanbao_share_parser.py "https://yb.tencent.com/..."
提示：仅粘贴链接（如 https://yb.tencent.com/...）无法解析，因为微信外访问该链接会被拦截；本工具不绕过此限制。
检测到输入的是一个 URL 链接，不是 HTML 源码 请按上方「如何获取 HTML 源码？」步骤，把分享页的完整源码复制进来；或者切换到「卡片文本」模式，粘贴从微信里复制的文字内容。
提示：适合解析元宝生成的 AI 总结卡，或手动复制的分享卡片文本。

        if (!currentConv) return;
        const type = btn.dataset.download;
        let content, filename, mime;
        if (type === 'md') {
          content = renderMarkdown(currentConv);
          filename = `yuanbao-${Date.now()}.md`;
          mime = 'text/markdown';
        } else {
          content = JSON.stringify({ meta: currentConv.meta, messages: currentConv.messages }, null, 2);
          filename = `yuanbao-${Date.now()}.json`;
          mime = 'application/json';
        }
        const blob = new Blob([content], { type: mime });
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = filename;
        a.click();
        URL.revokeObjectURL(url);
        showToast('已开始下载');
